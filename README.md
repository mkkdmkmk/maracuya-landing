# Maracuya — AI Product Landing Page

A premium landing page concept for Maracuya, an AI-powered chat and productivity product.

## Overview

The landing page was designed to communicate the product value clearly while creating a strong visual identity for an AI product.

The goal was to balance product storytelling with a clean and conversion-focused experience.
